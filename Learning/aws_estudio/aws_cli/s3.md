# aws bucket s3 commands



## Upload file with aws cli
```sh
aws s3api put-object \
  --bucket bucket-s3-name \
  --key dst-resource-name \
  --body source-resource-name

aws s3api put-object \
  --bucket bkt-s3-italianodevops \
  --key example-cli-uploaded.jpg \
  --body ./example.jpg
```

## delete file 

```sh
aws s3api delete-object --bucket bucket-s3-name  --key resource-name

aws s3api delete-object --bucket   bkt-s3-italianodevops --key example.jpg
```


## Delete bucket s3

```sh
aws s3api delete-bucket --bucket bkt-s3-italianodevops --region us-east-1
```
